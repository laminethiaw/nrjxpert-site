📐A.1 Formulaire

Circuits

U = Z·I   S = U·I* = P + jQ   ZL = jLω   ZC = 1/(jCω)   ω = 2πf
Triphasé : U = √3·V   P = √3·U·I·cos φ   QC = P(tan φ₁ − tan φ₂)   C = QC/(ωU²)

Réseaux

Zb = Ub²/Sb   Ib = Sb/(√3Ub)   ΔU/U ≈ (RP + XQ)/U²   ΔP = R(P² + Q²)/U²
Transformateur : Zcc = uccU²/Sn   Rcc = PccU²/Sn²   Xcc = √(Zcc² − Rcc²)
Load flow : Si* = Vi*ΣkYikVk   Gauss-Seidel : Vi = [(Pi − jQi)/Vi* − Σk≠iYikVk]/Yii

Court-circuit (CEI 60909-0)

I"k3 = cUn/(√3|Z₁|)   I"k2 = cUn/|Z₁ + Z₂|   I"k1 = √3cUn/|Z₁ + Z₂ + Z₀|
I"kE2E = √3cUn|Z₂|/|Z₁Z₂ + Z₁Z₀ + Z₂Z₀|   ip = κ√2 I"k   κ = 1,02 + 0,98e−3R/X   S"k = √3UnI"k

Machines tournantes

Synchrone : E = V + jXdI   P = (EV/Xd)sin δ   Q = (EV cos δ − V²)/Xd   capacité : p² + q² ≤ v² ; p² + (q + v²/Xd)² ≤ (vEfd max/Xd)²
Asynchrone : s = (ns − n)/ns   ns = 60f/p   Pméc = 3Ir²Rr(1 − s)/s   C ∝ V²   ZM = Un²/((ILR/IrM)·SrM) (CEI 60909, R/X = 0,10 ; 0,15 ; 0,42)

Protection et sélectivité

Temps inverse (CEI 60255-151) : t = TMS·k/((I/Is)α − 1)   SI : k = 0,14, α = 0,02   VI : 13,5 ; 1   EI : 80 ; 2
Marge de sélectivité chronométrique ≈ 0,3 s   Tenue des câbles : I²t ≤ k²S² (k = 143 Cu/PR)   Fusibles gG en série : calibre amont ≥ 1,6 × aval
Distance : Z = V/I   zones 80 % (instantané), 120 % (0,3 s), 200 % (1 s)   k0 = (Z₀ − Z₁)/(3Z₁)   Z0,éq = (ZAZB − Z0m²)/(ZA + ZB − 2Z0m)
TC : ALF′ = ALF·(RctIsn² + Sn)/(RctIsn² + Sb)

Régime de neutre et coordination d'isolement

Neutre isolé : Ic = 3ωC0Un/√3   phases saines : √3 × tension simple
Résistance : Rn = Un/(√3·Ilim)   Petersen : L = 1/(3ω²C0(1 + v))   Irésiduel ≈ Ic√(v² + r²)
Parafoudre : Ueq = Upl + 2SL/v (v = 300 m/µs)   marge BIL/Ueq ≥ 1,2   TOV : Ur ≥ k·Um/(√3·T), k ≈ 1,4 (terre) ou √3 (isolé, compensé)

Solaire

δ = 23,45 sin(360(284 + n)/365)   ωs = arccos(−tan φ tan δ)   Kt = H/H₀
Hβ = H[(1 − Hd/H)Rb + (Hd/H)(1 + cos β)/2 + ρ(1 − cos β)/2]
P = Pc(G/1000)(1 + γ(Tc − 25))   Tc = Ta + (NOCT − 20)G/800   E = Pc·Hβ·PR

PV autonome (méthode NRJXpert)

Qj = Ej/(U·ηconv·0,98·0,9)   C = Qj·autonomie(h)/24   Np,batt = ⌈C/(Cbatt·DoD)⌉
PWM : Np = ⌈Q′j/(H·kp·Imp)⌉, Ns = ⌈1,2U/(0,9Vmp)⌉   MPPT : Pc = Q′jU/(H·kp·fT·0,96), Ns = ⌈1,3U/(0,82Vmp)⌉   kp = 1 − pertes   régulateur et onduleur : × 1,25

Câblage

Ib = 1,25·I   In ≥ Ib   Iz0(S)·kθ·kg ≥ In   kθ = √((90 − θa)/60)
ΔU = b(ρL/S cos φ + λL sin φ)I   (b = 2 continu et monophasé, 1 triphasé sur V)   ρCu = 0,0225   ρAl = 0,036 Ω·mm²/m   λ = 0,08 mΩ/m

Éolien

P = ½ρAv³   f(v) = (k/c)(v/c)k−1e−(v/c)k   v̄ = cΓ(1 + 1/k)   ½ρc³Γ(1 + 3/k)
v(H) = v(Hmes)ln(H/z₀)/ln(Hmes/z₀)   E = 8 760∫P(v)f(v)dv(1 − pertes)   FC = E/(8 760Pn)
réseau : N = ⌈365B′j/Ean⌉   autonome : Creq = B′j·Aut/24/(DoD·ηbat), min CG(N, Aut) sous LPSP ≤ 1 − τcible

Pompage solaire

HMT = HG + PC   Eel = 2,725·V·HMT/(ηpηmηconv)   Pc = Eel/(Ens·ηc)
Qmax = πV/(2ΔT)   PH = Qmax·HMT/367   Pc = PH/(ηpηmηconvηc)·1 000/G   (V en m³/j, Q en m³/h, PH en kW)

Économie

CRF = a(1 + a)N/((1 + a)N − 1)   VAN = ΣFn/(1 + a)n   LCOE = Cact/ΣEn/(1 + a)n
taux réel = (1 + a)/(1 + i) − 1   subvention minimale = max(0, −VAN/I₀)

Réseaux intelligents (niveaux 6 et 7)

SAIDI = Σ(Ni·ti)/NT   SAIFI = ΣNi/NT   CVRf ≈ 2Z + I   RoCoF ≈ ΔP·f₀/(2H·ΣSn)
PNT = Einjectée − Ecomptée − Etechnique   précision = VP/(VP + FP)   rappel = VP/(VP + FN)   succès d'une trame = 1 − (1 − pⁿ)^(r+1)
