📐A.1 Formula sheet

Circuits

U = Z·I   S = U·I* = P + jQ   ZL = jLω   ZC = 1/(jCω)   ω = 2πf
Three-phase: U = √3·V   P = √3·U·I·cos φ   QC = P(tan φ₁ − tan φ₂)   C = QC/(ωU²)

Networks

Zb = Ub²/Sb   Ib = Sb/(√3Ub)   ΔU/U ≈ (RP + XQ)/U²   ΔP = R(P² + Q²)/U²
Transformer: Zsc = uscU²/Sn   Rsc = PscU²/Sn²   Xsc = √(Zsc² − Rsc²)
Load flow: Si* = Vi*ΣkYikVk   Gauss-Seidel: Vi = [(Pi − jQi)/Vi* − Σk≠iYikVk]/Yii

Short circuit (IEC 60909-0)

I"k3 = cUn/(√3|Z₁|)   I"k2 = cUn/|Z₁ + Z₂|   I"k1 = √3cUn/|Z₁ + Z₂ + Z₀|
I"kE2E = √3cUn|Z₂|/|Z₁Z₂ + Z₁Z₀ + Z₂Z₀|   ip = κ√2 I"k   κ = 1.02 + 0.98e−3R/X   S"k = √3UnI"k

Solar

δ = 23.45 sin(360(284 + n)/365)   ωs = arccos(−tan φ tan δ)   Kt = H/H₀
Hβ = H[(1 − Hd/H)Rb + (Hd/H)(1 + cos β)/2 + ρ(1 − cos β)/2]
P = Pp(G/1000)(1 + γ(Tc − 25))   Tc = Ta + (NOCT − 20)G/800   E = Pp·Hβ·PR

Stand-alone PV (NRJXpert method)

Qd = Ed/(U·ηconv·0.98·0.9)   C = Qd·autonomy(h)/24   Np,batt = ⌈C/(Cbatt·DoD)⌉
PWM: Np = ⌈Qd/(0.9·H·Imp)⌉   MPPT: Pp = QdU/(H·0.9·fT·0.96)   charge controller and inverter: × 1.25

Wiring

Ib = 1.25·I   In ≥ Ib   Iz0(S)·kθ·kg ≥ In   kθ = √((90 − θa)/60)
ΔU = b(ρL/S cos φ + λL sin φ)I   (b = 2 DC and single-phase, 1 three-phase on V)   ρCu = 0.0225   ρAl = 0.036 Ω·mm²/m   λ = 0.08 mΩ/m

Wind

P = ½ρAv³   f(v) = (k/c)(v/c)k−1e−(v/c)k   v̄ = cΓ(1 + 1/k)   ½ρc³Γ(1 + 3/k)
v(H) = v(Hmeas)ln(H/z₀)/ln(Hmeas/z₀)   E = 8 760∫P(v)f(v)dv(1 − losses)   CF = E/(8 760Pn)

Solar water pumping

TDH = HG + PC   Eel = 2.725·V·TDH/(ηpηmηconv)   Pc = Eel/(Ens·ηc)
Qmax = πV/(2ΔT)   PH = Qmax·TDH/367   Pc = PH/(ηpηmηconvηc)·1 000/G   (V in m³/d, Q in m³/h, PH in kW)

Economics

CRF = a(1 + a)N/((1 + a)N − 1)   NPV = ΣFn/(1 + a)n   LCOE = Cdisc/ΣEn/(1 + a)n
real rate = (1 + a)/(1 + i) − 1   minimum subsidy = max(0, −NPV/I₀)

Smart grids (levels 6 and 7)

SAIDI = Σ(Ni·ti)/NT   SAIFI = ΣNi/NT   CVRf ≈ 2Z + I   RoCoF ≈ ΔP·f₀/(2H·ΣSn)
NTL = Einjected − Emetered − Etechnical   precision = TP/(TP + FP)   recall = TP/(TP + FN)   frame success = 1 − (1 − pⁿ)^(r+1)

🧩A.6 Bibliography and standards

  • J. J. Grainger, W. D. Stevenson, Power System Analysis, McGraw-Hill.
